# E-commerce Sales Performance Analysis

**Tools:** SQLite, SQL, Excel

**What I did:**
- Analyzed 1,28,975 e-commerce orders using SQL
- Wrote 8 queries to find revenue, top states, categories, order status, and cancellations
- Built an Excel dashboard with charts and summary metrics
- Found key insights for business decisions

**Key Insights:**
- Total revenue: ₹7.85 crore
- Maharashtra has highest sales but also most cancellations
- 98% orders are B2C
- Average order value: ₹648.56
- Bengaluru, Hyderabad, Mumbai are top cities
